# Code of Conduct

We want this project to be a welcoming and respectful space for everyone.

Expected behavior includes:

- being respectful and constructive;
- welcoming different viewpoints and experience levels;
- focusing feedback on ideas and code; and
- protecting private information shared in the project.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, unwanted contact, and publishing someone else's private information.

Report conduct concerns privately to the repository maintainers through GitHub's private reporting or security reporting channel. Reports will be reviewed and handled confidentially where possible.
