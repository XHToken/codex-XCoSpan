# Security Policy

## Supported versions

Security fixes are expected for the latest `0.1.x` release. Older versions may not receive fixes.

## Reporting a vulnerability

Please do not disclose security issues in a public issue. Use GitHub's private vulnerability reporting for this repository, or contact the maintainers privately through the repository owner.

Include the affected version, steps to reproduce, impact, and a minimal proof of concept when possible. Do not include real secrets, personal data, or confidential documents; use synthetic examples.

The project will acknowledge a report when it is received, assess its impact, and coordinate disclosure with the reporter when a fix is available.
